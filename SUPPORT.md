## Getting Help

1. Check the documentation and the [Troubleshooting](docs/troubleshooting.md) page.
2. Search [existing issues](https://github.com/messeb/py-apple-health-data-pipeline/issues).
3. Ask in [GitHub Discussions](https://github.com/messeb/py-apple-health-data-pipeline/discussions).
4. For a confirmed bug, open an issue with the bug report template.

**Never attach your real health export, Parquet files or screenshots of your own data.** Reproduce
the problem with `make demo` (synthetic data) instead.

Security problems go through a [private advisory](https://github.com/messeb/py-apple-health-data-pipeline/security/advisories/new),
see [SECURITY](SECURITY.md).
